# ⚡ PowerCo Customer Churn Analysis

A data science project on why customers leave an energy provider, built from the BCG X job simulation on Forage.

> 🚧 **Status: work in progress.** Findings are added as each task is finished.

## What it does
Follows the 5-step data science process to investigate customer churn at PowerCo, an energy provider for small and medium-sized businesses, starting with the hypothesis that price increases are driving customers away.
